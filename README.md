# SKYBOOK — Airlines Ticket Booking System ✈️

A comprehensive Python console application designed to simulate an end-to-end airline reservation system. The project applies Object-Oriented Programming (OOP) principles alongside functional workflows to manage flight scheduling, aircraft administration, seat booking, and customer support handling.

---

## 🌟 Features Overview

### 👤 User Roles & Authentication
* **Admin Dashboard:** Secure authentication for administrators to manage fleet and flight schedules.
* **User System:** Account creation, secure login, and personalized user dashboard.

### ✈️ Aircraft & Flight Management
* **Plane Fleet Administration:** Dynamic plane generation with seat configurations (First Class, Business, Economy) and weight limitations.
* **Flight Operations:** Add, update, search, and view detailed flight routes with unique UUID generation.

### 🎫 Booking System
* **Seat Reservation:** Real-time seat availability verification across different seating classes.
* **Booking Management:** Issue electronic tickets, track booking history, and cancel reservations with dynamic seat releases using `tabulate`.

### 📩 Complaint Resolution System
* **User Feedback:** Interactive system for submitting operational complaints.
* **Admin Solver:** Admin workspace to review complaints and write custom solutions stored in persistent text files.

---

## 🛠️ Built With

* **Language:** Python 3.x
* **Core Concepts:** Object-Oriented Programming (Classes, Encapsulation, Methods), Data Structures
* **Libraries:** `uuid`, `random`, `time`, `os`, `tabulate`
